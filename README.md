-- Objetivo do Software
O BasketStats é um sistema desktop desenvolvido para auxiliar no gerenciamento de Jovens jogadores de basquete, 
permitindo o controle de estatísticas de atletas, cadastros de jogadores e treinadores, 
além de perfis personalizados e autenticação integrada com banco de dados relacional.

--Funcionalidades
Cadastro de Usuários:Permite o registro separado de novos Atletas e Treinadores com validação de e-mail e senha.
Sistema de Login:Tela de autenticação que valida os dados informados com o banco de dados MySQL para direcionar o usuário á sua respectiva página.
Gerenciamento de Perfil:Exibição dinâmica dos dados cadastrais e estatísticas do usuário logado .
Filtros e Consultas: Funcionalidade para listar e filtrar atletas de acordo com critérios estatísticos.
Persistência de Dados: Integração completa entre a aplicação Java (Swing) e o banco de dados relacional via JDBC para salvar e carregar as informações.
